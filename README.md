# 🐍 Python Snake Game

A classic Snake Game built with Python and the Turtle graphics module as part of my Python learning journey.

Control the snake, eat the food, grow longer, and try to achieve the highest score without hitting the walls or your own body!

## 🎮 Features

- Snake movement using the arrow keys
- Random food placement
- Snake grows when it eats food
- Score tracking
- Collision detection with walls and the snake's own body
- Game-over screen

## 🛠️ Technologies Used

- **Python**
- **Turtle Graphics**
- **OOP (Object-Oriented Programming)**

## 📚 Concepts Practiced

Through this project, I practiced:

- Creating classes and objects
- Class attributes, methods, and inheritance
- Importing and organizing code into separate modules
- Working with lists and loops
- Using coordinates with `xcor()`, `ycor()`, and `goto()`
- Keyboard events and movement controls
- Random number generation
- Collision detection and score management

## 🚀 How to Run

1. Install Python on your computer.
2. Clone this repository or download the ZIP file.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python main.py
```

## 🎯 Controls

| Key | Action |
|---|---|
| ⬆️ Up Arrow | Move Up |
| ⬇️ Down Arrow | Move Down |
| ⬅️ Left Arrow | Move Left |
| ➡️ Right Arrow | Move Right |
